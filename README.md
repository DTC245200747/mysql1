# BÀI TẬP TẠO BẢNG TRÊN MYSQL WORKBENCH

## 1. Tạo Bảng sử dụng giao diện MySQL Workbench (GUI)
- Bước 1: Mở MySQL Workbench, nhấp chuột phải vào schema `student-management` chọn `Create Table...` (hoặc mở rộng `student-management` -> nhấp chuột phải vào `Tables` -> chọn `Create Table...`).
- Bước 2: Tại mục Table Name nhập `Class`, thêm các trường thông tin (`id` chọn PK/AI, `name`) rồi nhấn `Apply` -> `Finish`.
- Bước 3: Tiếp tục nhấp chuột phải chọn `Create Table...` để tạo bảng thứ hai.
- Bước 4: Tại mục Table Name nhập `Teacher`, thêm các trường thông tin (`id` chọn PK/AI, `name`, `age`, `country`) rồi nhấn `Apply` -> `Finish`.
